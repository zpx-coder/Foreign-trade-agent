# v1.2需求列表
## 一.优化企业资料模块
1. 企业信息不需要填写国家，我们的面向的用户都是中国国内的
2. 城市应该可以通过下拉列表选择中国城市，同时支持输入模糊匹配搜索
3. 企业信息应该更细分一点，增加一些外贸交易中采购商对企业感兴趣的信息字段，还要增加比如企业特色等字段
4. 企业信息中增加图片类型的信息，如工厂实景，如证件资质照片
5. 产品信息中每个产品应该增加产品图片字段
6. 用户在注册时已经填写了企业名称，注册成功登录后企业资料中企业名称应该把注册时填的数据带过来


# v1.3需求列表
## 一.优化客户画像模块
1. 新增客户画像-公司规模应该可以多选
2. 新增客户画像-产品信息应该直接关联产品管理列表中的产品，而不是重新手动填写
3. 需要输入价格的地方应系统设定货币单位为美元，而不是让用户输入
4. 新增客户增加保存草稿功能，与列表中的草稿状态对应起来
5. 客户画像列值加几个字段：目标地区、目标行业、公司规模、预算
6. 已完成的客户画像应该支持用户二次编辑修改输入信息然后重新AI生成画像
